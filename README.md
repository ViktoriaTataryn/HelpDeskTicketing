Цей проект є RESTful API для системи технічної підтримки (Help Desk),
де користувачі можуть створювати тікети, а адміністратори — керувати ними та відстежувати прогрес.

Технологічний стек
Проект побудований з використанням сучасних технологій .NET:
Backend: ASP.NET Core API.
Security: JWT (JSON Web Tokens) для безпечної автентифікації та авторизації.
ORM: Entity Framework Core.
База даних: MS SQL Server.
Архітектура: розподіл на шари (Core, Entities, Storage) для забезпечення чистоти коду.
Документація: Swagger/OpenAPI.

Основний функціонал
Керування тікетами: створення, редагування та видалення запитів на підтримку.
Автентифікація: реєстрація та логін користувачів з генерацією JWT токенів.
Відстеження статусів: можливість моніторингу прогресу виконання кожного тікета.

Структура проекту
HelpDeskTicketing.Core — бізнес-логіка системи.
HelpDeskTicketing.Entities — моделі даних та сутності бази даних.
HelpDeskTicketing.Storage — репозиторії та контекст бази даних.
HelpDeskTicketing — основний проект API з контролерами.
